## Rubric

- **Answer support (0–2):** 0 = unsupported/wrong, 1 = partly supported, 2 =
  supported by the cited text.
- **Citation accuracy (0–2):** 0 = wrong/missing page, 1 = relevant document
  but imprecise page, 2 = cited page supports the claim.
- **Abstention (pass/fail):** question 10 should be clearly identified as
  unanswerable from the indexed filings.
